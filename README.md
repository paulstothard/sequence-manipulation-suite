# Sequence Manipulation Suite

This repository contains the generated static files for the public Sequence Manipulation Suite 3 (SMS3) site.

Open SMS3 here:

- <https://paulstothard.github.io/sequence-manipulation-suite/>

This GitHub Pages project URL is published from the `sequence-manipulation-suite` repository.

SMS3 runs as static HTML, JavaScript, and bundled reference data in your browser; normal sequence, table, and workflow inputs are not uploaded to an SMS3 server.

The optional Get Data and Send Data tools connect to external biological services. Get Data sends your accession, search terms, or region to the selected database when you click Retrieve or run a workflow containing Get Data. Send Data shares the displayed data or identifiers when you click Open or Send; some services require you to paste or upload the data on their website. External services apply their own privacy policies.
